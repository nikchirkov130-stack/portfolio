# Портфолио — 5 современных сайтов

Коллекция из пяти самодостаточных сайтов на актуальные темы: путешествия, гастрономия,
фитнес, мода и авто. Всё написано на **чистом HTML, CSS и JavaScript** — без фреймворков,
сборщиков и зависимостей. Акцент на визуализации данных, живых интеракциях и современном дизайне.

Готово к публикации на **GitHub Pages** из корня репозитория.

## Проекты

| # | Проект | Тема | Тип | Ключевая фишка |
|---|--------|------|-----|----------------|
| 1 | **Компас** (`travel/`) | Путешествия | Одностраничник | Параллакс-горы, интерактивная SVG-карта мира, анимированная статистика |
| 2 | **Вкус** (`food/`) | Еда | Одностраничник | Canvas-диаграммы КБЖУ, конструктор блюда с live-пересчётом |
| 3 | **Импульс** (`fitness/`) | Фитнес | Одностраничник | SVG прогресс-кольца, график активности, калькулятор ИМТ/калорий |
| 4 | **Ателье** (`fashion/`) | Мода | Многостраничник (4 стр.) | Lookbook с фильтрами и lightbox, история бренда, контакты бутиков |
| 5 | **Мотор** (`auto/`) | Авто | Многостраничник (4 стр.) | Конфигуратор с мгновенной ценой и графиками характеристик |

Корневой `index.html` — хаб-портфолио со ссылками на все проекты.

## Структура

```
.
├── index.html          # хаб-портфолио
├── css/style.css
├── js/main.js
├── travel/             # одностраничник
├── food/               # одностраничник
├── fitness/            # одностраничник
├── fashion/            # 4 страницы: index, collection, about, contact
└── auto/               # 4 страницы: index, models, configurator, about
```

Каждый проект изолирован в своей папке и содержит `index.html`, `css/style.css`, `js/main.js`,
`assets/img/` (локальные изображения), `favicon.svg` и `CREDITS.md` (источники фото). У
многостраничников CSS/JS и каталог изображений общие на все страницы.

## Запуск

Откройте `index.html` двойным кликом — всё работает локально без сервера.
Либо поднимите простой локальный сервер:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Портфолио: 5 сайтов на чистом HTML/CSS/JS"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root`**.
Сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Технологии и принципы

- **Семантический HTML5**, доступность (aria, `focus-visible`, skip-link), SEO и Open Graph.
- **Современный CSS3**: custom properties, Grid, Flexbox, glassmorphism, адаптив 320–1920px.
- **Чистый JavaScript**: `IntersectionObserver`, `requestAnimationFrame`, Canvas 2D, SVG-анимации.
- **Деликатные анимации** с поддержкой `prefers-reduced-motion`.
- **Ноль зависимостей** — только Google Fonts по CDN; всё остальное работает офлайн.

## Изображения

Все изображения скачаны локально в `assets/img/` каждого проекта — внешних CDN (picsum,
pravatar, randomuser) больше нет, сайты полностью автономны. Превью в корневом `index.html` —
это реальные скриншоты проектов (`assets/img/preview-*.jpg`). Источники и лицензии каждой
фотографии указаны в файлах `CREDITS.md` внутри папок проектов.

## Что можно доработать

- Заменить контакты в корневом `index.html` (переменная `EMAIL` в `js/main.js`, ссылка на GitHub).
- При желании заменить демонстрационные фотографии из `assets/img/` на свои собственные.
